# ZU4EV以太网迁移验证记录

日期：2026-10-22。器件XCZU4EV-SFVC784-2-I，Vivado2024.2。板卡通过JTAG识别为xczu4_0并成功配置；电脑以太网2协商到1 Gbps。

## 功能与仿真

- Python：81项通过，其中17项以真实本地UDP套接字验证包边界、窗口、请求/回包丢失、乱序、有界重试、错误来源及校验失败。
- 全部15个RTL自检通过；网络核心199个完整GMII事务逐字节对照，包含ARP、FCS、IP/UDP checksum、应用CRC、8种算法、完整HOG/Band流程及重复/冲突请求。
- RGMII使用官方原语模型验证32字节双向DDR顺序、EN/ER编码和转发时钟。异步邮箱验证最大1038字节、奇数checksum、读反压、忙时保护、丢弃和复位。
- 新增窗口GMII测试逐字节对照48个回包，覆盖8包突发、最早缓存槽重发、冲突、请求乱序、端点隔离、错误保留缓存和会话失效。队列验证满8槽、失败回滚、80包并发读写和复位；组包器验证1024字节无气泡输出及100拍反压。
- 原有9个算法/协议自检保持通过；Band算法自检包含当前4张点阵图片及3个合成/变换样例。

## 速度与范围

- 原生1920×1080复制往返0.675484秒，返回4,147,200字节并与原始RGB565完全相同，重试0次。
- 有效图像吞吐6.140 MB/s，双向应用负载合计98.234 Mbps。该值不含文件转换、参考检查和预览绘制。
- 物理链路1 Gbps；普通图像DATA默认8包窗口，两侧整包队列并行收发，窗口内旧请求直接回放结果。HOG/Band仍使用单包命令事务。吞吐取指定窗口三次逐字节校验成功试验的中位耗时，实际业务吞吐与链路速率分别记录。
- Band仍为16～512 × 16～512近水平点阵；每行至少5点，末两行同步。逐项回归不代表真实码流误码率或HOG检测准确率。

## 实现与时序边界

- 综合层级包含eth_udp_stack、img_stream_top、eth_image_rx、tx_mailbox及RGMII接口，与移植方案一致。
- 7323 LUT、6935寄存器、124/128 BRAM、5 DSP；无latch，DRC无错误。
- 内部建立裕量2.708 ns，保持裕量0.008 ns；无无时钟或未约束内部端点。
- CDC无critical项。4个CDC-6为整包队列的4位Gray提交/释放指针，三级同步并约束源至首级最大延迟8ns和bus skew 4ns；80个CDC-15为原ARP稳定元数据。XPM双时钟块RAM保存队列数据与描述符，不整体切断时钟域，bus skew检查通过。
- 参考板PHY RXDLY/TXDLY和PCB走线未提供外部I/O延迟数值。保留15项缺失输入/输出延迟提示；RGMII外部接口尚未正式签核，内部收敛及功能实测不能替代板级时序参数。
