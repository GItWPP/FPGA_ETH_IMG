# v1.7.0 · ZU4EV 千兆以太网图像 / 视频工作台

1280×720视频的Sobel处理使用FPGA行缓存与流水线，上传RGB565、回传GRAY8。电脑解码打包与收发并行，Windows原生UDP模块配合64包窗口，完整视频实测25.01 FPS。

- 实板与EXE：731帧全部处理，零跳帧、零重传；暂停、继续、停止、重播通过。
- 验证：123项软件检查、20项RTL自检，旧图像算法、HOG和Band均实板回归。本轮没有验收30 FPS。
- 内部建立/保持裕量：1.944/0.012 ns；BRAM 104/128，URAM 8/48。
- 使用：下载配套EXE和eth_img.bit，板卡192.168.1.12:1234，电脑192.168.1.18/24；选择Sobel边缘检测、原视频尺寸、逐帧处理。

Release保留2026-10-23验收时的完整运行包和源码快照，SHA256与本地验收记录一致。GitHub主分支另含发布工作流、忽略规则与小分辨率CI桌面的测试适配；RTL及上位机处理逻辑保持验收版本。仓库原有MIT LICENSE保留。

发布脚本先检查包、EXE及bit的SHA256，再上传到草稿Release，全部完成后公开。GitHub Actions使用只限本仓库的临时令牌；二进制输入保存在release-assets/v1.7.0分支。源码主分支不包含Vivado构建缓存、环境或用户视频。

RGMII外部I/O delay仍需依据PHY/PCB参数完成板级签核。详细结果见[验证记录](验证记录.md)。
