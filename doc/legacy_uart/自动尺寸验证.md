# 自动原图尺寸：实现与验收

日期：2026-10-21。软件自检、冻结EXE和COM11实板验收通过。

## 当前使用方式

双击 `tools/dist/UART_Image_Tool_Auto.exe`，选择 COM11 和1500000，打开图片后直接点击发送。默认“自动识别原图”从文件解码结果读取宽高，范围为宽1..1920、高1..1080，支持任意整数宽高和奇数像素数，不限固定预设。

自动模式中宽高只读显示；连续打开新图片会更新宽高，发送结果和保存图保持本次原图尺寸。预览图适应窗口缩小显示。

需要主动改变大小时，选择“手动输入”或尺寸预设。选择“自动识别原图”或点击“原图尺寸”即可恢复自动。超限图片显示实际尺寸和范围提示，用户可以选择手动缩放，程序不会静默修改原图发送尺寸。

## 数据流

上位机解码图片（应用JPEG EXIF方向），读取实际宽高，转换RGB565并将宽高写入START。FPGA根据每帧START里的宽高计算总字节数，处理分块并回传。协议和当前1920×1080 FPGA bitstream保持不变。

图片准备逻辑在 tools/uart_image.py 的 load_source_image / prepare_image 中，GUI和命令行共用。未给出宽高时使用原尺寸；显式指定宽高时才缩放。

```powershell
python .\tools\uart_image.py send .\photo.png --port COM11 --mode gray --output .\received.png
```

手动缩放仍可使用成对的 --width / --height。
