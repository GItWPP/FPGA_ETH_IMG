# HOG与独立算法模块验证

日期：2026-10-21。工程：`./project_uart\project_uart.xpr`，板卡AX7Z020B，XC7Z020-2CLG400，50MHz，J20串口COM11/1.5Mbps/8N1。保持原XDC、独立project_uart目录及用户工程配置，新增源文件引用。

## 已完成内容

八种图像算法独立为各自`*_top.v`文件；`img_pixel_proc`只做模式选择和握手，复杂算法有子模块。`img_process_top`连接普通算法选择器和`hog_detect_top`；`img_command_top`连接普通会话与独立HOG命令控制器。

HOG首版为320×240灰度、64×128窗口、8像素步长、495窗口；特征提取与线性SVM均由FPGA执行，上位机负责图像缩放、补边、阈值筛选、NMS、坐标映射与绘框。候选得分不是概率。

## 软件与RTL验证

- Python 45项单元测试通过：原有协议、八种图像算法、自动尺寸、视图操作，以及HOG整数特征、模型维度、坐标映射、NMS、序号/长度、32位有符号得分解析。日志：`tools/hog_all_unit_tests.log`。
- 原有四个RTL自检回归通过：262144单像素输出、2096邻域窗口、真实串口位级场景、完整1080p的4147200字节和4050个DATA分片。
- `tb_hog_math`通过261121种梯度差分组合、512组恢复除法、边界与反压测试。
- `tb_hog_uart_ctrl`通过102项事务：76800字节上传、重复包/冲突重发、重复RUN、读取边界、错误不破坏缓存、普通算法与HOG的会话切换。这里的计算引擎使用握手替身；数值正确性另由完整算法自检验证。
- `tb_hog_detect_top`对训练外正/负样本合成场景检查10800个直方图值、40716个Q10特征、495个SVM得分，与独立标量Python模型逐项一致。连续处理均匀灰度帧，检查存储重用和公开同步读接口。计算耗时7808397拍，即50MHz下156.168ms。
- RTL/TB共36文件的模块头、分区、显式类型及逐行具名连接检查通过。完整回归命令为`sim/run_sim.ps1`，日志`sim/hog_all_sim.log`。

## 模型质量与适用范围

从公开INRIA Person镜像随机选384张正样本、128张背景，共512张，固定revision和SHA256。按完整图像编号分组，408张用于训练、104张用于验证；验证窗口79正、300负，共379。线性SVM的C从0.01/0.1/1.0中以验证集选择0.1。Q12权重量化前后，379个验证窗口的正负判定完全一致。

|真实类别|判为背景|判为行人|
|---|---:|---:|
|背景|297|3|

这是用于参数选择的窗口级验证，非独立最终测试、非官方INRIA划分，也没有整图AP指标。合成场景默认阈值0有5个候选框，最高得分框覆盖行人，同时存在多余候选；自然背景样例无候选，高梯度压力图有4个误报。可提高界面阈值减少候选，但会增加漏检。当前模型是单尺度直立行人原型，远处/小尺寸/遮挡/姿态变化仍需多尺度、难负样本训练及场景级评估。
