## Vivado 2019.2

器件 xc7z020clg400-2，时钟约束周期 20 ns，综合、布局布线和 bitstream 生成完成。

```text
PART=xc7z020clg400-2
CLOCK_HZ=50000000 BAUD=1500000
SETUP_SLACK_NS=12.169
HOLD_SLACK_NS=0.108
BITSTREAM=./tools/build/uart_img.bit
```

实现后资源：683 LUT（1.28%）、755 FF（0.71%）、2 个 RAMB18（1 个 BRAM Tile，0.71%）、1 DSP（0.45%）。无锁存器、无缺失时钟、无未约束内部端点。异步 UART 和外部复位端口使用明确的 false-path，内部同步路径保留正常时序检查。

DRC 为 0 Error、0 Critical Warning，保留 4 个 Warning：DPIP-1 两项和 DPOP-2 一项针对 START 图像长度乘法的流水建议，当前 50 MHz 时序已通过；ZPS7-1 一项针对纯 PL 工程没有实例化 PS7。本次仅使用 PL 接口，未对 PS 软件/DDR 功能作验证。初版出现的 RAMB18 异步控制警告已通过同步复位修复，修复后重跑两组仿真和实现。

报告：tools/build/utilization.rpt、timing_summary.rpt、drc.rpt、cdc.rpt。report_cdc 不分析没有源时钟的串口输入；RX 两级 ASYNC_REG 和外部复位同步链另外由 RTL 与单时钟结构核查。

用户确认 COM11（CH340）连接 J20，JTAG 已连接。唯一 JTAG 目标为 Digilent/210512180081，扫描到 arm_dap_0 和 xc7z020_1。已通过 JTAG 下载当前 bitstream，启动状态 HIGH；无调试核提示是正常的信息项。

## 使用状态

板卡当前已经运行此串口图像工程。串口测试结束后 COM11 已关闭释放，上位机可以直接选择 COM11、1500000、打开图片并发送。JTAG 配置掉电失效，需要重新下载 tools/build/uart_img.bit；没有写入 QSPI Flash。

本次未自动按物理 KEY1，复位中断场景通过 RTL 仿真验证。未进行长时间连续传输或断电启动测试；当前验收覆盖本记录列出的测试。
