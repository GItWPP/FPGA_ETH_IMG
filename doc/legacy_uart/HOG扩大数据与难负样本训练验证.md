# HOG扩大数据与难负样本训练验证

2026-10-21，模型由D2A8B58B更新为7803AC83。工程仍使用用户创建的project_uart；本轮沿用HOG特征版本1、320×240输入、64×128窗口及现有独立RTL模块，主要更新SVM权重、偏置和训练工具。

## 数据与训练

固定镜像revision `003a9c033cb85c6b28f512854dcda7e08602616f`，数据由512张扩为2181张：1269张96×160人物样本、912张背景。背景统一经过与上位机一致的320×240等比例缩放/补边，再用于随机负样本、挖掘和评估。

相同编号裁剪、完全重复像素及水平镜像像素合并成1334组；旧版使用过的512张图片关联378组，全部归入训练，避免旧模型已经见过新独立测试图片。剩余新组按固定哈希划分。原始场景编号不完整，因此不声称官方INRIA划分或严格原始场景隔离。

GUI默认阈值保持0，方便与旧版直接比较；验证集的等召回比较阈值单独记录为-0.2858。阈值为SVM距离分数，不是概率。

## 独立测试比较

人物指标为51个已归一化、居中的窗口分类；背景指标为122张训练外背景图，每图495个窗口，共60390个。误框统计使用统一NMS（IoU=0.35），未额外应用GUI的补边区域过滤。

|同为阈值0|旧模型|新模型|
|---|---:|---:|
|人物窗口检出|49/51|48/51|
|人物窗口召回|96.08%|94.12%|
|背景误框总数|281|81|
|背景平均误框/图|2.303|0.664|

同阈值下，背景误框减少71.17%，人物窗口多漏检1个。该结果不能表述为“人物识别准确率提高71%”。

在各自验证集校准的比较阈值下，旧模型阈值-0.1417，新模型-0.2858；独立测试均检出49/51个人物窗口，背景误框为434→196，减少54.84%。窗口级平均精度为0.6044→0.8455；这是给定窗口集合的分类指标，不是整图目标检测mAP。

测试正样本仅51个，且仍以直立行人为主。定位准确率、半身、坐姿及严重遮挡需要带框的对应场景单独评估。

## 定点、RTL及实现

- 向量化训练特征与已有独立标量参考逐项一致；新增分组隔离、梯度邻域、全部窗口布局和整数SVM检查。Python共49项测试通过。
- Q12权重量化在验证集55个人物窗口上，无分类变化。53955个背景窗口在校准阈值下无变化；阈值0下有1个临界窗口变化（约0.00185%）。最大分数差0.000857，小于由量化误差推导的0.012903上界。上述独立测试表使用实际量化模型。
- 7组RTL回归全部通过，包括完整1080p控制、UART、HOG数学边界、102项HOG控制事务、整帧10800个直方图/40716个特征/495个得分及连续均匀帧。
- Vivado2024.2综合、布局布线及bitstream通过：50MHz，建立裕量5.724ns，保持裕量0.053ns；2782 LUT、2345寄存器、55.5个BRAM等价块、4 DSP。
- 综合/实现0错误、0严重警告；默认DRC保留46条普通警告（DSP流水建议、LUT布局和纯PL的PS7提示），无规则豁免，无BRAM异步控制警告。

日志分别为`tools/hnm_unit_tests.log`、`tools/hnm_quantization_check.log`、`sim/hnm_all_sim.log`和`project_uart/build/`各报告。
