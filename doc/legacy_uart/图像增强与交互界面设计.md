# 图像增强与交互界面设计

目标：保留现有UART收发与八位模式能力字段，增加FPGA暗部增强和彩色锐化，并把上位机改为以图片为中心、可缩放平移的工作台。

## 增强算法与接口

全部逻辑继续使用sys_clk=50 MHz、低有效复位；UART仍为1.5 Mbps / 8N1，不增加外部端口或时钟域。

- 模式6：Gamma暗部提亮，gamma=0.5。RGB565的R5/B5分别输出`floor(sqrt(c*31))`，G6输出`floor(sqrt(c*63))`，在原生颜色位宽内定义精确整数结果。FPGA使用固定查找表，不在运行时计算平方根；黑白端点保持。
- 模式7：3×3彩色锐化。三个颜色分量分别计算`5*中心-上-下-左-右`，钳位至R/B的0..31、G的0..63，再拼接RGB565。沿用邻域分片和边界复制。

模式0..5不变。PING能力位图从3F增加至FF。模式6走普通RGB565 DATA；模式7走现有滤波分片DATA。START保持6字节，模式总线保持3位。上位机按模式集合{3,4,5,7}选择邻域分片，不能再用“模式编号>=3”作为条件。

模块分工仍为UART/包RX → 接收BRAM → img_ctrl → img_pixel_proc → 结果BRAM → 包/UART TX。Gamma作为单拍弹性通道，与原图/灰度/反色握手一致；锐化在窗口握手后锁存九像素，下一阶段计算并寄存输出。中值排序、均值/Sobel状态保持原行为。状态转移、窗口锁存、输出和valid分别由对应进程负责，输出反压期间保持。

## 上位机布局

顶部标题与简短说明，右侧为串口/波特率摘要和“设置”开关；下方白色操作栏放打开图片、模式选择、发送并处理和保存结果。串口详情与尺寸设置默认折叠，可展开修改。左右两个等宽图片卡片分别显示发送图和FPGA结果，底部为进度与状态。

图片卡片各自提供滚轮缩放（以鼠标所在图像位置为锚点）、鼠标左键拖拽平移、放大/缩小、1:1和适应窗口，双击恢复适应窗口。缩放只改变视图，不修改图像或发送宽高。缩放只渲染可见区域，避免1920×1080高倍率时生成巨大位图；原图与结果均可检查细节。窗口调整大小时，适应模式自动重排，手动模式保持倍率。

自动识别文件原始尺寸和EXIF方向、手动指定发送尺寸、RGB565参考校验、线程收发、结果保存继续保留。发送期间禁用会改变任务的输入设置，图片视图仍可操作。

## 验证

核对Gamma查找表的所有RGB565输入、锐化的边界/饱和/彩色分量，再进行UART全链路与原有模式回归。图像视图检查鼠标锚点、拖拽、缩放边界、窗口重排以及视图操作不改变源图/发送尺寸；通过渲染截图检查默认和最小窗口布局。构建和时序通过后在COM11实测新算法，重新打包独立EXE并验证文件加载、模式选择、鼠标交互、实际收发和结果保存。
