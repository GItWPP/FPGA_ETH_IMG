# 图像滤波与边缘检测验证

日期：2026-10-21。工程：UART_IMG；用户创建的Vivado工程为project_uart/project_uart.xpr。

## 当前交付

- FPGA模式：0原图、1灰度、2反色、3彩色3×3均值去噪、4彩色3×3中值去噪、5灰度Sobel边缘。
- 上位机：tools/dist/UART_Image_Tool_Filter.exe，Windows x64单文件，无需安装Python。
- bitstream：project_uart/build/uart_img.bit，已通过已授权JTAG目标下载到xc7z020_1，只配置PL，不写Flash。
- 波特率1,500,000、8N1、COM11（USB-SERIAL CH340，J20）；所有FPGA逻辑为50 MHz时钟域。
- 自动尺寸保持为宽1..1920、高1..1080；支持奇数宽高、单行、单列，输出与输入尺寸相同。

均值/中值分别处理RGB565的三个颜色分量，保持彩色。Sobel为灰度梯度幅值，噪声也可能产生边缘；需要先去噪时，可先处理并保存中值结果，再打开该结果使用Sobel。当前未提供一包内的多算法级联。
