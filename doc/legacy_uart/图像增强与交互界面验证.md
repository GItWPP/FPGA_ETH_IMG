# 图像增强与交互界面验证

日期：2026-10-21。沿用本工程及用户现有project_uart/project_uart.xpr。

## 交付与使用

新版独立程序：tools/dist/UART_Image_Workbench.exe，Windows x64单文件，无需安装Python。

打开图片后选择“Gamma 暗部提亮”或“彩色锐化（3×3）”，点击“发送并处理”。已有六种模式保留。点击右上角“设置”可展开串口、波特率及发送尺寸；默认选中USB串口、1500000 baud及自动原图尺寸。

两侧图片都支持：

- 滚轮放大/缩小，保留鼠标所指的图像位置。
- 鼠标左键拖拽平移，大小图片均可移动。
- 双击恢复适应窗口，“适应”按钮功能相同。
- “1:1”查看原始像素，以及+/-缩放按钮；范围1%..3200%。
- 适应模式随窗口重排；手动倍率在窗口调整大小后保持。

这些操作仅改变预览。发送尺寸仍由自动/手动尺寸设置决定，保存的结果始终为完整回传图像。Ctrl+O打开图片、Ctrl+S保存结果、Ctrl+Enter发送。发送期间仍能查看图片细节，任务相关设置暂时禁用。

## FPGA增强定义

模式6为Gamma=0.5暗部提亮：R5/B5输出floor(sqrt(c*31))，G6输出floor(sqrt(c*63))，FPGA用固定查找表实现；保持纯黑、纯白端点及单拍弹性输出。模式7为彩色3×3锐化：每分量5×中心−上−下−左−右，钳位至原生颜色范围，四边复制最近像素。

PING模式位图由3F扩展到FF。Gamma使用普通DATA，锐化使用邻域DATA，START及包布局不变。新上位机能在发送前识别所选模式是否受固件支持。
