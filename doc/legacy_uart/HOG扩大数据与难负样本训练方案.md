# HOG扩大数据与难负样本训练

目标：沿用当前整数HOG特征版本1和独立算法模块，通过扩大数据及训练集内难负样本挖掘减少背景误检，并用独立测试集评估召回变化。

## 数据与隔离

- 固定公开镜像revision `003a9c033cb85c6b28f512854dcda7e08602616f`，从原512张扩为全部2181张（1269张人物、912张背景），保存SHA256，并与固定Git对象校验。
- 相同编号裁剪、完全重复像素、水平镜像像素采用并查集成组；同组只能出现在同一分区。
- 旧版使用过的512张及其关联组全部放入训练侧。新组按固定哈希70%训练、15%验证、15%独立测试；新测试集同时未参与旧模型训练及参数选择。
- 原始场景编号在镜像中不完整，结果只能声称按上述规则隔离，不声称官方划分或严格原始场景隔离。
- 用户的test1.png和people1.jpg保留作应用回归样例。半身、坐姿及遮挡的任务差异单独记录。

## 训练与挖掘

1. 正样本中心窗口及小幅位置扰动，背景每图随机选12个初始窗口。
2. 比较线性SVM的C=0.01/0.1/1.0。只使用验证集选择参数。
3. 用模型遍历训练背景的全部8像素步长窗口，选得分较高的误检/近边界窗口，每图每轮最多16个，排除已使用坐标并抑制高度重叠窗口。
4. 累加难负样本后重训，最多3轮。每一轮保存窗口来源、位置索引、挖掘前得分，便于复查。
5. 验证集按人物窗口约90%召回校准比较阈值，按背景误框数/图选择检查点，窗口平均精度作为并列比较依据。GUI默认阈值沿用0；校准阈值用于展示等召回下的比较，不直接替代默认值。
6. 冻结模型和阈值，再对独立测试集一次性比较旧模型与新模型：阈值0、各自校准阈值下的召回、背景误框数/图和窗口误报率。窗口AP不等同于整图目标检测AP。

向量化训练特征须与已有独立标量参考逐项一致。Q10特征、Q12权重、Q22得分及3780维布局保持一致。训练完成先导出候选文件，再根据验证结果更新ROM和上位机模型。旧模型、旧bitstream与原始测试分数归档可恢复。
